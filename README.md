# Commit Message for Codex and ChatGPT

Адаптация [Suuunboy/commit-message-skill](https://github.com/Suuunboy/commit-message-skill)
для Codex и ChatGPT. Сообщения коммитов на основе изменений, в стиле проекта,
без автоматически добавленной AI-атрибуции.

## Возможности

- Анализ staged diff; отдельная обработка unstaged и untracked изменений.
- Работа с diff подключённого репозитория, PR, вставленным патчем или описанием.
- Подбор стиля по требованиям проекта и истории; Conventional Commits по умолчанию.
- Английский по умолчанию, другой язык по явному запросу.
- Переписывание сообщений, amend/revert/fixup и разделение несвязанных изменений.
- Запрос сообщения возвращает текст. Явный запрос сделать коммит разрешает
  соответствующее действие в рамках доступных инструментов и прав.

## Установка в Codex

Скопируйте папку `skills/commit-message` целиком в одно из мест обнаружения:

- Для проекта: `<repository>/.agents/skills/commit-message`.
- Для пользователя: `~/.agents/skills/commit-message`
  (Windows: `%USERPROFILE%\.agents\skills\commit-message`).

Вызывайте явно:

```text
$commit-message Напиши сообщение для staged-изменений
```

Скилл также допускает автоматический выбор по подходящему запросу.
Не устанавливайте несколько копий с одинаковым именем без необходимости.
Готовый локальный архив скилла: `dist/commit-message-skill.zip`.
Полный пакет плагина: `dist/commit-message-plugin.zip`.

## ChatGPT

В средах с поддержкой standalone skills добавьте папку скилла через доступный
интерфейс Skills. Для распространения через систему плагинов репозиторий содержит
корневой `plugin.json` и папку `skills/`. Пакет не требует MCP, API-ключей и скриптов.
Установка локальных/репозиторных плагинов зависит от интерфейса и настроек
workspace; наличие манифеста само по себе не публикует плагин в каталоге.

После установки выберите скилл через `@` и передайте diff или описание изменений.
Без инструментов доступа к репозиторию ChatGPT использует предоставленные данные.
Скилл сам по себе не предоставляет доступ к Git или локальным файлам.

В чате без поддержки skills можно вставить инструкции из
`skills/commit-message/SKILL.md` как обычный запрос и приложить diff. Это ручное
использование инструкций без автоматического обнаружения скилла.

Примеры запросов:

```text
Напиши сообщение коммита по этому diff. В проекте используется Conventional Commits.
Перепиши сообщение на русском, сохрани scope и номер задачи.
Предложи отдельные сообщения для несвязанных изменений, ничего не коммить.
```

Примеры больше не предлагают додумывать детали реализации из краткого описания.

## Проверка

Скилл не содержит исполняемых скриптов. Проверьте его на staged/unstaged diff,
описании без репозитория, явном выборе языка, несвязанных изменениях и запросе
только текста. Проверка установки в ChatGPT требует среды с этой возможностью;
локальная валидация файлов её не заменяет.

Официальная документация формата и установки:
[Build skills](https://learn.chatgpt.com/docs/build-skills),
[Package your plugin](https://developers.openai.com/plugins/build/plugins).
